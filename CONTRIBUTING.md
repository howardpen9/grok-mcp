# Contributing to grok-mcp

Thanks for your interest in contributing! This guide covers everything you need to get started.

## Development Setup

```bash
# Clone the repository
git clone https://github.com/howardpen9/grok-mcp.git
cd grok-mcp

# Install dependencies
npm install

# Build the project
npm run build

# Run tests
npm test

# Run tests in watch mode (during development)
npm run test:watch
```

## Project Structure

```
src/          # TypeScript source code
tests/        # Vitest test files
dist/         # Compiled output (generated by `npm run build`)
```

## Branch & Commit Conventions

### Branch Naming

- `feat/description` — new features
- `fix/description` — bug fixes
- `docs/description` — documentation changes
- `refactor/description` — code restructuring
- `test/description` — test additions or fixes
- `chore/description` — tooling, dependencies, build

### Commit Messages

We follow [Conventional Commits](https://www.conventionalcommits.org/):

```
<type>(<scope>): <short description>

<optional body>
```

**Types:** `feat`, `fix`, `docs`, `test`, `refactor`, `chore`, `perf`, `ci`

**Examples:**
```
feat(tools): add grok_consult tool for multi-turn reasoning
fix(mcp): handle missing API key gracefully
docs: update README with Cursor setup instructions
test: add unit tests for grok_chat tool
```

## Pull Request Checklist

Before submitting a PR, verify:

- [ ] **Tests pass** — `npm test`
- [ ] **Build succeeds** — `npm run build`
- [ ] **No debug logging** — remove `console.log()` and temporary comments
- [ ] **README updated** if behaviour or configuration changes
- [ ] **Commits follow conventional format** — squash if needed
- [ ] **PR description** explains what changed and why

## Adding a New Tool

1. Define the tool in `src/tools/` following the existing pattern
2. Register it in the tool registry
3. Add tests in `tests/`
4. Update `README.md` with tool documentation

## Running the MCP Server Locally

```bash
# Build first
npm run build

# Start the server
npm start
```

The server communicates over stdio. To test with an MCP host, point it at `node /path/to/dist/index.js`.
